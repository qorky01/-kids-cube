# 🧊 큐브 도우미

8살도 혼자 쓸 수 있는 3×3 큐브 맞추기 도우미예요.

- **내 큐브 맞추기**: 진짜 큐브의 색을 한 면씩 칠해서 알려주면, 20번 안팎으로 돌려서 맞추는 방법을 한 단계씩 3D 그림으로 보여줘요.
- **화면 큐브 놀이**: 화면 속 큐브를 섞고, 버튼으로 돌려 보고, "맞춰줘"를 누르면 맞추는 과정을 구경할 수 있어요.
- **혼자 맞추는 법 배우기**: 층별 풀이 7단계(흰 십자 → 흰 모서리 → 가운데 층 → 노란 십자 → 옆 색 → 노란 모서리 자리 → 모서리 돌리기)를 경우별 예제와 주문으로 따라 해요.
- **큐브의 비밀**: 조각의 종류, 가운데가 안 움직이는 이유, 되돌리기, 공식(주문), 층별 맞추기, 신의 숫자 20, 못 맞추는 큐브까지 3D로 직접 눌러 보며 배워요.

사용: https://qorky01.github.io/-kids-cube/

풀이 계산은 [cube.js](https://github.com/ldez/cubejs) (Kociemba 2단계 알고리즘, MIT), 3D는 [three.js](https://threejs.org) (MIT)를 씁니다.
